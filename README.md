# ⚖️ Uz Law Archive

Uz Law Archive is an open-source AI-powered legal document archive designed for storing, searching, analyzing, and processing Uzbekistan legal documents using modern NLP and LLM technologies.

## 🚀 Project Goal

This project aims to:

* Digitize legal documents
* Build searchable legal archives
* Enable semantic search
* Integrate Large Language Models (LLMs)
* Implement Retrieval-Augmented Generation (RAG)
* Create AI-powered legal assistance systems

for Uzbekistan legal resources and constitutional documents.

# ⚡ Installation

## 1. Clone the repository

```bash
git clone https://github.com/maqsud571/uz-law-archive.git
cd uz-law-archive
```

---

## 2. Create virtual environment

```bash
python -m venv venv
```

### Windows

```bash
venv\Scripts\activate
```

### Linux / macOS

```bash
source venv/bin/activate
```

---

## 3. Install dependencies

```bash
pip install -r requirements.txt
```

---

## 4. Run the server

```bash
uvicorn main:app --reload
```
